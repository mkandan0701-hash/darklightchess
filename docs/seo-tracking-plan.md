# SEO Tracking Plan — Darklight Chess Academy

## Current state: no analytics installed

The site currently has **no Google Analytics 4, Google Tag Manager, or any other analytics installed** — this was confirmed during the audit and the business owner deliberately chose to defer wiring it up in this round (see `docs/seo-audit.md`). This means **none of the work in this project can be measured yet.** Setting up GA4 and Google Search Console should be the very next action taken, before judging whether any of these changes are working.

## Step 1 (prerequisite): set up measurement

1. **Google Search Console** — verify `https://darklightchess.com` (domain property, using DNS verification, is the most robust option) and submit `https://darklightchess.com/sitemap-index.xml` (already generated by the site's build). This is free and gives real Google-search data — do this even before GA4.
2. **Google Analytics 4** — create a GA4 property, add the measurement ID, and add the `gtag.js` snippet to the site (a placeholder location and TODO comment can be added to `src/layouts/BaseLayout.astro` once the ID is available). Without this, none of the "organic enquiries," "WhatsApp clicks," or "demo bookings" metrics below can be measured automatically.
3. Once GA4 is live, set up basic event tracking for:
   - WhatsApp FAB clicks (`.whatsapp-fab` and the footer WhatsApp link)
   - Phone link clicks (`tel:` links)
   - Enquiry form submissions (the existing form already fires a `fetch` on submit — a GA4 event can be added alongside it)
   - "Book a Free Demo" CTA clicks across pages

## What to monitor once measurement is live

### Google Search Console
- **Organic clicks** and **impressions** — overall trend, and broken down by page.
- **Average CTR** and **average position** — watch these per query, not just site-wide averages.
- **Top landing pages** — confirm the new service pages (`/chess-academy-coimbatore/`, `/chess-classes-for-kids-coimbatore/`, etc.) start appearing here over time, not just the homepage.
- **Top queries** — specifically watch for the brief's primary keyword list appearing:
  - chess academy in Coimbatore
  - chess classes in Coimbatore
  - chess coaching in Coimbatore
  - chess classes for kids in Coimbatore
  - best chess academy in Coimbatore
  - (the full keyword list from the brief is in the project's original SEO instructions — track rank movement for all of them monthly, not just these five)
- **Coverage / Indexed pages** — confirm all intended pages (homepage, 7 service pages, published blog posts) show as "Indexed," and that draft blog posts (not yet published) correctly do NOT appear, since they aren't built into the site until `draft: false`.
- **Core Web Vitals report** — watch for any pages flagged for poor LCP/CLS/INP, especially the homepage (heaviest page, most images).

### Google Analytics 4 (once installed)
- **Organic sessions/users** trend, filtered to Organic Search channel.
- **Organic enquiries** — form submissions attributed to organic sessions.
- **WhatsApp clicks** and **phone clicks** as conversion events.
- **Demo bookings** — track distinctly from general enquiries if the form's "Course" field lets you separate "Free Demo Class" submissions.
- **Landing page performance** — which of the 7 new service pages actually drives engagement/conversions, to prioritize future content investment.

### Manual / periodic checks
- **Google Business Profile Insights** (once the profile is verified — see `docs/local-seo-citations.md`) — search views, map views, direction requests, calls initiated from the listing.
- Spot-check the primary keyword list in an incognito browser window monthly to sanity-check rank movement (not a replacement for Search Console data, but useful for local-pack visibility which Search Console doesn't fully capture).

## Suggested cadence

- **Weekly:** glance at Search Console for any sudden drops (indexing issues, manual actions, big ranking swings).
- **Monthly:** full review — organic clicks/impressions trend, keyword position movement on the priority list, top landing pages, indexed page count, Core Web Vitals status, and enquiry/WhatsApp/phone conversion counts once GA4 is live.
- **Quarterly:** revisit `docs/content-calendar-coimbatore.md` — which published posts are actually driving traffic, and adjust the next batch of drafts accordingly.
